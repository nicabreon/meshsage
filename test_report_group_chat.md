# Stability Report: Group Messaging Protocol (E2EE)

## 1. Overview
Laporan ini mendokumentasikan hasil pengujian end-to-end (E2E) sistem perpesanan grup pada platform `meshsage`. Pengujian difokuskan pada keamanan (E2EE), distribusi kunci otomatis, dan keandalan pengiriman pesan saat anggota offline.

## 2. Test Environment
- **Infrastructure**: Multi-node Docker containers with subnet isolation.
- **Nodes**: 
    - Alice (`client-a`): Member
    - Bob (`client-b`): Member
    - Charlie (`client-c`): Member (Target for offline testing)
    - Relay (`relay-server`): Mailbox and Bootstrap node.

## 3. Test Cases & Results

### Case 1: Group Initialization & Key Sharing
- **Description**: All members join group `#prod`. Sender keys are generated locally and shared via secure 1:1 channels (Double Ratchet).
- **Result**: **SUCCESS**.
- **Evidence**:
    - `[GROUP HANDSHAKE] Sharing our local key ... via Double Ratchet` logged on all nodes.
    - `Received and saved Group Session Key` logged upon reception.

### Case 2: Real-time Online Messaging
- **Description**: Alice sends a message to `#prod` while Bob and Charlie are online.
- **Result**: **SUCCESS**.
- **Evidence**:
    - Bob and Charlie received and decrypted the message via GossipSub (with Mailbox fallback due to subnet isolation).
    - Digital signature verified: `[Group Security] Message from @Alice verified with Digital Signature.`

### Case 3: Offline Fan-out via Mailbox
- **Description**: Charlie is stopped. Bob sends a message to `#prod`. Charlie is restarted and performs `/fetch`.
- **Result**: **SUCCESS**.
- **Evidence**:
    - Bob's log: `Offline message stored successfully nodes=1` (targeted at Charlie's mailbox coord).
    - Charlie's log (after restart & `/fetch`):
        ```text
        [GROUP E2EE] Decrypted Result: Pesan rahasia saat Charlie offline.
        [Group #prod] @Bob (Offline): Pesan rahasia saat Charlie offline.
        ```

## 4. Technical Architecture Verified
- **Layer 1 (Key Exchange)**: X3DH Handshake -> Double Ratchet 1:1 -> GKEY Transmission.
- **Layer 2 (Group Encryption)**: Sender Keys (AES-GCM) -> GossipSub Broadcast.
- **Layer 3 (Offline Resilience)**: Mailbox Fan-out -> Automatic fallback if direct peer is unreachable.
- **Layer 4 (Integrity)**: Digital Signatures (Ed25519) on every group payload.

## 5. Conclusion
Sistem perpesanan grup `meshsage` telah **STABIL** dan memenuhi standar keamanan tinggi dengan enkripsi ujung-ke-ujung (E2EE) yang tetap terjaga baik dalam kondisi online maupun offline. Integrasi antara skema *Sender Keys* dan *Mailbox Relay* terbukti sangat efektif untuk jaringan P2P yang terfragmentasi.
